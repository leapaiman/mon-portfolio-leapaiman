PORTFOLIO DE LÉA PAÏMAN — FICHIERS DU SITE

Fichiers :
- index.html : contenu et structure de la page
- style.css : design, couleurs, typographies et responsive
- script.js : menu mobile
- images/ : dossier où ajouter tes images (optionnel pour l'instant)

APERÇU SUR TON MAC
1. Décompresse le dossier si besoin.
2. Double-clique sur index.html pour l'ouvrir dans ton navigateur.
3. Pour modifier le code, ouvre les fichiers dans un éditeur comme Visual Studio Code.

AVANT PUBLICATION :
- Remplace le lien LinkedIn générique dans index.html par l'URL exacte de ton profil.
- Vérifie l'adresse mail.
- Personnalise les textes du parcours et les descriptions de projets pour qu'ils correspondent précisément à tes missions.
- Ajoute tes propres visuels. Les cartes de projets ont actuellement des aplats de couleur comme placeholders.

PUBLICATION GRATUITE AVEC GITHUB PAGES :
1. Crée un compte GitHub si tu n'en as pas.
2. Crée un nouveau dépôt public nommé exactement : tonpseudo.github.io (remplace tonpseudo par ton identifiant GitHub).
3. Ajoute index.html, style.css, script.js et le dossier images à la racine du dépôt.
4. Dans Settings > Pages, sélectionne la branche main et le dossier /(root), puis enregistre si l'option apparaît.
5. Attends la publication, puis ouvre https://tonpseudo.github.io.

Le site est un site statique : il ne nécessite ni WordPress, ni abonnement d'hébergement payant. Le domaine personnalisé est facultatif et généralement payant.
